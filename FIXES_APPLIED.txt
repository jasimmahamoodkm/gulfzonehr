THE PROBLEM
================================================================================

❌ Employees could not login after creation
❌ Reason: Default "Employee" role was not being assigned
❌ Impact: System appears successful but employees have no permissions

================================================================================
ROOT CAUSES (2 CRITICAL BUGS)
================================================================================

BUG #1: Wrong Database Column Name
───────────────────────────────────
Location: src/app/api/admin/create-employee/route.ts:136
Wrong:    .eq('role_name', 'Employee')
Fixed:    .eq('name', 'Employee')
Why:      Column is actually named 'name' in roles table

BUG #2: Missing Required Database Field
────────────────────────────────────────
Location: src/app/api/admin/create-employee/route.ts:160
Wrong:    { user_id, role_id }
Fixed:    { user_id, role_id, company_id }
Why:      UNIQUE constraint requires all 3 fields
